# Outside Medical Records → One-Page Summary

Synthesizes scanned outside-records PDFs into a one-page chart summary
(HPI, FamHx/SocHx, PMH, PSH, Meds, Objective, Assessment, Plan) with:

- **Click-to-source** — every Assessment phrase is anchored to the
  verbatim PDF snippet it came from. Click to highlight in the PDF pane.
- **ACC/AHA-grounded Plan** — Plan recommendations are NOT generated by
  the LLM. They come from a curated rule set
  (`backend/guidelines/acc_aha.json`) whose `recommendation_text` is
  emitted verbatim along with the original guideline citation.
  Nothing is asserted without a matching rule.

> ⚠️ For de-identified test data only. Not for real PHI in v1.

## Pipeline

```
PDFs ──► [Claude vision per page] ──► page facts (each w/ pdf_id, page, verbatim snippet)
                                          │
                                          ▼
                            [Claude synthesis] ──► one-page JSON
                            (HPI/PMH/PSH/Meds/Objective/Assessment)
                                          │
                                          ▼
                          [Rule-based ACC/AHA planner] ──► Plan
                          (verbatim recommendation + citation chip)
```

## Run it

Requires Python 3.11+, Node 20+, and `ANTHROPIC_API_KEY`.

```bash
# 1. Backend
pip install -r backend/requirements.txt
python samples/generate_synthetic_patient.py   # only first time
export ANTHROPIC_API_KEY=sk-ant-...
uvicorn app.main:app --reload --app-dir backend --port 8000
```

```bash
# 2. Frontend (new terminal)
cd frontend
npm install
npm run dev    # http://localhost:3000
```

Drop `samples/outside_records/*.pdf` into the upload, click **Run pipeline**.

## Alternative: headless pipeline

```bash
python backend/run_pipeline.py samples/outside_records/*.pdf
# inspect data/<case_id>/summary.json
```

## Extending the guidelines

`backend/guidelines/acc_aha.json` is the source of truth for the Plan.
The current set is a seed covering high-yield HFrEF GDMT, AF
anticoagulation, ASCVD lipid management, HTN target, and chronic
coronary disease antiplatelet. To add a rule, append to `rules[]` with
the schema described in `backend/README.md`. The planner uses
**fail-closed semantics** — if a required precondition can't be
evaluated, the rule does not fire.
